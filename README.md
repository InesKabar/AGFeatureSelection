# AGFeatureSelection

Feature Selection using Genetic Algorithms.

## Project Overview

This project demonstrates how Genetic Algorithms can be used for feature selection in machine learning.

The algorithm searches for an optimal subset of features by using evolutionary operations such as selection, crossover, and mutation.

The project also compares several machine learning classifiers and evaluates their accuracy.

## Dataset

The project uses a Breast Cancer dataset containing multiple features used to classify breast cancer cases.

## Machine Learning Models

- Linear SVM
- RBF SVM
- Logistic Regression
- Random Forest
- AdaBoost
- Decision Tree
- K-Nearest Neighbors
- Gradient Boosting

## Genetic Algorithm

The feature selection process uses:

- Population initialization
- Fitness evaluation
- Selection
- Crossover
- Mutation
- Multiple generations
